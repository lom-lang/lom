Playground boundaries (by design)

  
    
    
  • Recursion — Lom's depth guard fires at 300 frames with structured RUNTIME diagnostics first; pathologically nested sources can still exceed the browser engine's native stack limit (a few hundred frames) and terminate as a trap.
    • 
    
  • Files — the file module is a virtual single file: reads return the current editor content, fix --apply writes back to the editor, and any other path fails with ENOENT.
    • 
    
  • Arguments — env::args() sees only the virtual script path /playground.lom; user arguments after -- cannot be passed from this page.
    •
