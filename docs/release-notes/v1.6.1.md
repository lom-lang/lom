# v1.6.1 — first public checkpoint (2026-10-03)

Release notes for the first externally published checkpoint. Tag: `v1.6.1` (`e6b807b`, CI run `37125504909` #259, six jobs green).

## What Lom is

Lom is a programming language designed around the **LLM repair loop**: when a model writes broken Lom, the language itself diagnoses it precisely (structured diagnostic codes on every rejection) and, where a mechanical fix is safe, applies it (`lom fix --apply`). The repair interface is machine-readable by design — the same `lom-fix/v1` plan format an LLM agent consumes.

## Why this version

v1.6.1 closes the twenty-sixth in-system review's three P3 openings (R114/R115/R116) in one batch, leaving the remediation ledger empty and the seven-item pre-publication checklist fully green:

- **R115** — the experimental L2 self-hosted subset compiler now rejects same-file duplicate `fn` definitions in single-file mode, mirroring the host's NAM002 error face (gated to single-file compilation; cross-package name collisions keep the host's NAM006 deterministic-order semantics).
- **R114** — the v1.6.0 classifier claim ("141 negative messages classify, 0% fallback") is scope-annotated at every claim site: it is a corpus-scope claim; ~29 further combination messages outside the corpus constructively reach the L2G fallback (code nonempty, message intact, non-misleading).
- **R116** — SECURITY.md's CI supply-chain version references refreshed to the actual `@v5`/Node 24 state.

## Evidence baseline at this tag

- **Repair loop on real models**: 31 error_repair tasks (incl. warning-level and "host-accepts/L2-rejects" genres) — deepseek-v4-pro+thinking and glm-5.3, 10 samples each @ t=1.0: pass@1 96.8% / 98.7%, with the 24-task overlap subset at 480/480 across both models ([report](../../eval/REPORT-2026-10-03-err-repair-31.md)).
- **Self-hosting strong quine**: the 12,591-line L2 compiler compiles its own source to a 272,293-byte WASM module, byte-identical from both sides; re-verified on every CI run (`verify_selfcomp --bootstrap`, 14/14).
- **Core**: zero third-party crates, zero `unsafe`, 561 Rust unit + 31 integration tests, three-OS CI; the language surface (syntax / 20 reserved words / diagnostic codes / 43 builtins) has been frozen since v1.0 (2026-09-02) — every release since is remediation/evidence work, verified by a 368-case cross-compiler harness (196 behavior pairs + 8 package projects + 164 negative locks).

## Honest boundaries

- The L2 self-hosted compiler is **experimental** (strict subset; every host-vs-L2 divergence is registered and carries an `[L2xxx]` code + repair hint via `tools/l2fix.py`).
- The 26 review rounds are **in-system adversarial reviews** (agent-run, evidence-based) — engineering hygiene, not external peer review; grades never extrapolate across baselines.
- No prebuilt binaries ship with this release: build from source with `cargo build --release` (zero dependencies, no network fetch of crates).
