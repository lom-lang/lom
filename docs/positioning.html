3. 证据链（按各自限定口径复验）

  • LLM 修复题实测：error_repair 评测任务 24 个（含 4 个 warning 级修复题）双模型 × 10 采样 temperature=1.0 全过（480/480，2026-09-16 补测——20 题于 09-07、119/120 于 09-16、121/122 于 09-16 新题即测）。该数字证明模型候选按任务预期输出通过，不证明 lom fix --apply 的 High 动作安全，也不证明历史 prompt 内嵌诊断仍与当前编译器一致（R55/R60）。
  • 双后端语义对齐：树遍历解释器 + 手写零依赖 WASM 后端，10000 个随机生成程序/项目实例 stdout+退出码逐字一致（差分测试四期，含递归 enum、三包依赖链、file/env 深形态）；已知分歧全部文档化（§11f 八条）并有探针守护白名单不腐坏。
  • 自举自证：用 Lom 写的 5703 行解释器（lexer/parser/checker/evaluator/json）三层自证——WASM 载体上的自举解释器解析自身源码，dump 与宿主原生逐字一致。
  • LLM 实测：评测集现值 121 任务，实测分层带时点——113 任务集四模型单采样（2026-08-31）、116 任务集双模型 × 10 采样（2026-09-07）pass@1 = pass@5 = pass@10 = 99.1%（无偏估计）、error_repair 24 题双模型 × 10 补测全过（2026-09-16，含全部后补修复题）；唯一系统性失败是刻意的 prompt 歧义锚点题 078；唯一无采样记录的是其明确版对照题 118（Q4 单采样对照 10/10）。
  • 治理与审查：语言面 v1.0 冻结（变更须 RFC）；九轮维护者对抗性审查——R1-R54 已关闭，第九轮总评 B、R55-R61 待整改；宣称数字由 CI 机器对账（doc_audit 65 项 + claims.json 分项回加）。
  • 供应链：Rust crate 零第三方依赖、零 unsafe；CI 仍依赖 GitHub Actions 与第三方 rust-toolchain action，不能把 crate 零依赖扩大成“全部供应链风险为零”。手写 JSON/LSP 的可审计性真实存在，其协议正确性缺口也已由 R58/R59 证明。

4. 判定边界（本页宣称的适用范围——必读）

  • "只此一家"= 在已调研样本中：深读竞品 Zero 与 Vera 两家（docs/archive/ 第 2 轮，一手原文）+ 第 4 轮发现的社区目录 agentlanguages.dev（35 家"为 AI agent 写"的语言，2026-06-14 时点快照，描述层面全量扫描）——目录三营（表征/验证/编排）的共同底色是"防错"，以修复闭环为核心卖点的条目为零；Codong（"fix/retry fields"）与 X07（"quickfixes … deterministically"）有修复部分元素（描述层）。宣称的准确含义是"在已扫描的新兴 agent-native 语言样本（2 家深读 + 35 家目录）里，修复执行闭环完成度领先"，非世界范围的概念独占。
  • 机制层无原创（第 3 轮调研结论）：结构化建议（span+替换文本）、置信度分级（rustc 的 applicability 四级 vs Lom 三级）、迭代自动应用到不动点（cargo fix 的 fixpoint 循环）——机制三件套在 Rust 生态已完整存在多年；ESLint --fix/TS code fixes/Roslyn 为同类。Lom 的真实差异是四维组合：把修复闭环作为语言的存在理由（repair-native，非工具链附属）+ lom-diag/lom-fix schema 作为语言契约 + fix_corpus 修复语料回归网 + 高温 LLM 实测口径——该组合截至第 4 轮检索（rustc/TS 生态 + 35 家 agent 语言目录描述层面）未见先例；目录内 Codong/X07 具备修复机制的部分元素，为该判断再添两个机制层例证（相对 Rust/TS 生态的成熟度与规模，Lom 均为后来者——如实记录；详见 docs/archive/ 第 3/4 轮调研）。
  • "独有"的最终检验在发布后的外部反应：Lom 当前未发布；前八轮为内部委托审查，第九轮为新维护者独立敌手式审查，均不等于外部同行审计。R55 等阻塞项关闭前，本页不得单独作为对外完成度证明。

5. 如实标注：对方领先项

  • Vera：Z3 形式化契约验证（Lom 的验证形态是 golden/差分/自举/审查的工程证据链，非形式化证明）。
  • Zero：expected/actual 结构化诊断字段（Lom 目前揉在 message 文本；列为冻结期外的候选演进）；sub-10KiB 原生二进制（Lom 是 WASM 目标）。
  • MoonBit：生态与工具链规模（IDE/包管理/多目标成熟度，1.0 在途）；编辑器内生成时纠错路线。
