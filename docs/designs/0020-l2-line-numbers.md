## §1 读码供料要点（规划者复核后采信）

1. **发射机制**：`subset_err(msg)` 是纯前缀函数（L2509：`"L2.2 子集不支持: " + msg`），失败语义由 **264 处调用点**的 `Err(...)` 包装完成，冒泡至 main **L12584 全文件唯一打印点** `println("codegen error: [" + classify_l2(msg) + "] " + msg)`。另有 **40 处裸 `Err("...")`**（22 内部错误哨兵 + 18 用户面消息，含全部"未定义变量"）走同一通道。
2. **行号信息现状**：lexer 层**位置完备**——每个 token 是三元组 `{t: Tok, ln: Int, cl: Int}`（换行只计数不产 token）；lex/parse 两个诊断通道**已输出** `ln:cl [码] 文案` 格式（位置在码前）。parse 之后的全部 pass（预扫/collect_sigs/类型检查/codegen）遍历 AST、**不持 token 游标**；AST 仅 5 类节点带零星位置字段（ExIdent/StAssign/StHole/ExMatch 结束行/ItFn 起点——**0017 §1.2 记载"仅 4 节点"漏了 ItFn，本设计如实更正登记**），且检查/编译侧消费点几乎全部 `_` 丢弃。
3. **L718 "span 不建模"准确边界**：self_comp.lom L718 注释"span 不建模——dump 契约不含位置"——指**完整 span 不进 L2 的 AST enum**（对齐宿主 `--dump-ast` 不打印 span 的输出契约，verify_selfhost dump 对拍依赖此），**不是编译器全程无位置**（token 层与 lex/parse 诊断层位置体系现成）。
4. **发射点分布**（264 处按所在函数）：builtin_rv 46 / infer_ex 33 / collect_sigs 16 / ty_vt_with_params 15 / 其余 154 处散布 50+ 函数；其中 **211 处所在函数签名直持 AST 参数**、**53 处为纯 String/Map 深链工具**。0017 登记的"~118 处主要簇"口径 = callee/StAssign 锚可低成本锚定的发射点集合。
5. **兼容面**：verify_selfcomp **148 条码+文案双锁全部 substring 包含匹配**（前缀/后缀附加式行号零破坏，中插锁定子串才破）；eval 127/128/129 prompt 逐字内嵌当前格式 L2 输出三段（需重采——0017 裁决点 3 甲先例）；l2fix 的 `CODEGEN_LINE` 正则对"码后行号"形态仍匹配、对"码前行号"形态失配（需同步一行）。

## §2 方案空间

- **甲（建议）＝名字锚输出层查表**：新增一个**token 流线性预扫** `build_name_pos`——扫 token 表收集"标识符名 → 首现 (ln, cl)"映射；输出层 L12584 从 msg 提取首个引号名 `'([^']+)'`（l2fix 已有同款提取正则先例）查表，命中则输出带位置格式。**零 AST 改动（守 L718）、零发射点签名改动（264+40 处自动受益）、渐进覆盖（无名消息保持现格式）**——对齐 0017"输出层映射零侵入"哲学。锚表取 token 流而非 AST 5 类位置节点的原因：内建名（'map_set' 等只出现在 import/调用点，两处 AST 均无位置）与未定义名（从未进入任何声明）**只有 token 层有锚**——token 流方案覆盖二者，AST 方案覆盖不到最大簇 builtin_rv。
- **乙＝发射点传参**（0017 §4 登记的"主要簇传参 ~118 处"原意）：给发射点所在函数链传位置参数。波及 118+ 处签名、只覆盖持 AST 的 211 处中的部分、53 处纯工具深链仍盲——精度高于甲（真出错点）但工程面大一个量级。
- **丙＝AST 加 span**：0017 已排除（违反 L718 dump 契约对拍），列作对照不再议。

**精度边界（甲方案如实登记）**：位置语义 = **该名字在源码中的首次出现处**，非出错表达式的精确 span——同名多处出现时指首现（如"赋值 'x' 类型不符"可能指向 x 的定义处而非本次赋值处——对修复仍有定位价值）；消息无引号名或名字从未以标识符出现（如语法定义的类型组合描述）则无行号。此精度上限是本方案的既定设计属性，登记入 SPEC 与 README 边界句。

## §3 甲方案详细设计

1. **新预扫 `build_name_pos(ts, n) -> Map<String, String>`**（值打包 `"ln|cl"`，沿 perr 打包先例）：线性扫 token 表，遇标识符形态 token 且名字不在表内则记首现 (ln, cl)。实施首步核对两处细节：Tok 枚举中标识符变体的确切形态（TkIdent(String)？名字如何携带）与 ts/n 在 parse 完成后至 main 输出层的存活传递路径（main 作用域内可用性）。预估 ~30-40 行 Lom。
2. **输出层改动（L12584 唯一拼装点）**：从 msg 用引号名提取（无引号名则查表跳过）→ 命中输出 `codegen error: ln:cl [码] 文案`，未命中保持 `codegen error: [码] 文案`。~10 行。
3. **l2fix 同步**：`CODEGEN_LINE` 改为位置可选组 `codegen error: (?:(\d+:\d+) )?\[(L2[A-Z]\d{3}|LEX\d{3})\] (.*)`（与 SYNTAX_LINE 的码前位置形态统一）；`--self-check` 断言随批核（164 负例码解析 100% 应保持）。
4. **断言面（verify_selfcomp）**：148 条双锁**零破坏**（substring）；新增一条**汇总断言**：全部 codegen 负例中"消息含引号名者，输出应含非空 `ln:cl` 段"（覆盖登记，失败列出缺行号的负例清单——若实测有合法 miss 形态，随批登记豁免清单而非放宽断言）。
5. **eval 三题重采**：127/128/129 的 L2 段按新编译器实采（solution/expected 零改动——0017 裁决点 3 甲先例）；eval_prompt_check 校验面不含 L2 文本段（既有登记口径）。
6. **quine 与基线连锁**：self_comp.lom 增行（预估 +40~60 行）→ quine 字节变化（新值随批实测双侧一致）；verify_selfcomp 368 项数不变；doc_audit 的 J 锚（quine/self_comp 行数）随批同步。
7. **升版**：L2 工具行为 patch → **v1.7.2**（v1.6.1"L2 工具行为 patch"先例）。

## §4 L2 转正判据盘点（清单草案——转正本身是独立用户裁决，本节只是决策输入）

1. **修复闭环三件套**：结构化码 ✓（v1.6.0）+ 码进修复通道 ✓（l2fix）+ **行号定位（本批，若交付）**。
2. **行为锁定**：196 正例对拍 + 164 负例双锁 + bootstrap 14/14 强 quine 全绿为常态。
3. **已知边界全部登记或收口**：L2 包展开不查同文件 fn 重复（登记）；MUT002 分歧族（登记）；行号首现锚精度边界（本批登记）。
4. **评测实证**：error_repair L2 面 3 题在双模型采样下表现稳定（127 的 Option 解包缺口是真实能力面非工具面）。
5. **一次带 L2 面的独立审查轮**复核上述四项（转正前最后一个大包收官后发起，用户裁决）。

## §6 裁决点（呈用户）

1. **路线**：甲 = 名字锚输出层查表【建议——零 AST 改动守 L718、零发射点签名改动、覆盖含内建名/未定义名的最大簇、渐进兼容】/ 乙 = 传参方案（精度=真出错点，但 118+ 处签名波及、53 处深链工具仍盲）。
2. **输出格式**：`ln:cl` 置于码前（`codegen error: 12:5 [L2P001] 文案`——与既有 lex/parse 通道三通道统一；l2fix 正则同步一行）【建议】/ 置于码后（l2fix 零改动，但三通道格式分叉、将来统一成本更高）。
3. **断言升级**：新增"含名字锚负例行号非空"汇总断言【建议——覆盖登记可机检】/ 仅保 148 现锁（行号静默缺失不可见）。
4. **批范围**：行号 + §4 转正判据盘点随设计文档交付（转正独立另裁）【建议】/ 仅行号。

## §7 边界与禁止

- 不改 264+40 处发射点签名（甲路线下）；不触宿主 src/（零桌面行为变化）；不加 AST 位置字段（L718）；不新增宿主诊断码（§14 冻结面无关——L2 工具码族不变，仅格式）。
- "绝不能这样修"（负向锁定）：①不得为行号给全部 AST 节点加 span（违反 dump 契约对拍）；②不得让输出层在查表 miss 时伪造 `0:0`（谎报位置不如无位置——诚实诊断设计）；③不得改 verify_selfcomp 匹配逻辑为整行匹配（会放大 148 锁的维护成本且无必要）。
