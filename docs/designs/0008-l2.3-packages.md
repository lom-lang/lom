## 1. 背景与范围

json 批后 L2.3 剩包/return 两批。**包批**目标：让被编译程序可以是**多文件包项目**（lom.toml
声明本地路径依赖，跨包 import 用户函数/枚举/变体）。

**本批目标**（对拍口径：双产物行为级一致——宿主 `lom build <main.lom> --target wasm`
vs L2 产物，stdout + rc 逐字）：

1. 包项目（主文件 + 依赖包）可编译，跨包调用/包内 enum/`as` 别名双侧一致；
2. import 语义对齐宿主 wasm_codegen：内建 exports 表 → known_packages 放行 →
   未知模块编译错误（堵 L2 现存"非内建 module 静默落空"缺口）；
3. 宿主新增**包展开工具出口**（与宿主 merge 同源逻辑）。

**明确不在本批**（负例登记或后续）：包发布/注册中心（长期挂账）；`lom build`
无文件参数的 cwd 口径包检查流程（宿主既有功能，不涉对拍）；主项目目录
非 main 的其他 .lom 文件（宿主语义本就不加载）；return 语句批（下一批）。

## 2. 现状与宿主参照系（读码结论 @ e73e2dc，供料逐处实证）

### 2.1 宿主包语义（设计锚点，任何路线对齐此语义）

「按 **main.lom 所在目录**发现 lom.toml（7.8/D 包二期修复后语义——cwd 曾致漂移）；
依赖图 DFS（循环 PKG003/清单名与依赖键一致）；**包目录全部 .lom 按文件名排序收集**
（不递归子目录）；**包 items 在前、主 items 在后**（确定性：包按根路径排序）；
**fn 重名主文件（后定义）赢、enum/变体重名首个赢且均不报错**（"LLM 责任保证
不同包不重名"——interpreter.rs L539）；包符号是普通用户 fn/enum 不进内建分派；
import 只做符号许可 + 别名映射（wasm_codegen L531-538 known_packages 只注册
import_aliases；L554-556 未知模块编译错误）」。产物恒为**合并后单 wasm 模块**。

### 2.2 L2 现状拒绝点

| 位置 | 现状 |
|---|---|
| 驱动层（main L9261-9295） | 单文件三步流（file_read→lex/parse→build_module→写 hex）；**无目录列举能力**（宿主 file 模块仅 read/write/append/exists 四内建，43 内建冻结不可加） |
| ItImport（collect_sigs L8911-8983） | 只认 string/list/map/json 四内建模块；**其他 module 名（math/file/env/io/任意包名）整条 import 静默落空**——module 名缺口开放，与宿主 PKG005 口径不一致 |
| comp_call（L4387） | 静默落空的下游：调用时"调用未知函数"（误导性延迟报错） |
| register_enums（L8168/L8201） | enum/变体重名即 `Err`——与宿主"重名静默首个赢"**行为分叉点** |
| ItFn（L8882-8909） | fn 重名无检查后写覆盖（各占槽位）——与宿主槽位复用行为一致仅 hex 尺寸差 |

### 2.3 关键架构事实（供料结论，规划者确认）

- **L2 两遍式平坦 items 结构无单文件假设**——拼接后单遍编译结构上直接成立
  （与宿主 merge_packages_for_wasm 同构）。
- **宿主 merge 是 AST item 级拼接**；在源码文本层拼接对合法 Lom 语义等价
  （顶层 item 无跨文件词法状态；差异仅诊断行号——宿主 build wasm 路径对包
  源码本就不做逐文件诊断）。
- **L2 无法自行发现包**（无目录列举内建；解冻加内建违反冻结铁律；lom.toml
  约定入口文件名偏离宿主语义）——"读 lom.toml 自发现"路线在冻结约束下不可行。
- 宿主解释器路径**丢弃包内 import**（"包内 import 暂不传递"interpreter.rs L560，
  符号因全图注册而可用）；宿主 WASM 路径保留包内 import 并由 known_packages
  放行——两种形态行为等价。

## 3. 裁决点 1：实现路线

- **丙+丁组合：宿主包展开出口 + L2 吃展开单元 + L2 包名放行（建议）**。
  - **丙（宿主侧）**：新增 CLI 子命令 `lom pkg-expand <main.lom>`——复用宿主
    `resolve_dependencies` + `collect_lom_files` 的**收集与排序逻辑**（单一事实
    源，不重写包语义），在**源码文本层**输出合并产物：依赖包源码（包序+文件序
    同宿主）+ 主文件源码；**剥除包内 import 语句**（对齐宿主解释器语义，产物
    更净；主文件 import 保留——它是符号许可与别名的载体）。纯工具面（CLI
    子命令先例：info/fix/repl/lsp/build/doc/fmt），不动语言面。
  - **丁（L2 侧）**：驱动 argv 增可选第三参**包名逗号清单**
    （`self_comp.lom -- in.lom out.hex liba,libb,libc`）；L2 把包名注册进
    known_pkg 集合；ItImport 分派序对齐宿主 wasm_codegen：内建四模块 →
    known_pkg（只做别名注册+放行，符号已在拼接 items 里）→ **未知模块编译
    错误**（对齐宿主 PKG005 口径，堵静默落空缺口）。math/file/env/io 的
    import 由 L2 自身 import 集已知语义——被编译程序 import 这些模块中
    L2 未支持的内建时按现行逐名校验拒（现状不回退）。
  - **对拍口径**：verify 脚本对包用例先 `lom pkg-expand` 得展开单元喂 L2，
    宿主侧照旧 `lom build <main.lom>`——**两侧编译单元同为宿主包系统的
    合并产物**（等价性由宿主 Rust 代码单点保证，无脚本重写漂移）。架构
    叙事对齐 cargo/rustc 先例：包管理器（宿主）负责展开，编译器（L2）
    吃编译单元。
- **甲：L2 真自发现（读 lom.toml + 递归读包）**——冻结约束下不可行（需
  file_list_dir 内建=违反 43 内建冻结；或单文件包限定=偏离宿主"全部 .lom"
  语义）。仅在内建解冻后可重议。
- **乙：Python 外层拼接（宿主零改动）**——拼接语义由脚本定义，与宿主
  merge 的等价性无测试锁定（宿主 merge 有 cli.rs L513 测试锁），漂移风险
  由脚本正确性承担；且包语义出现在两处代码源。不建议。

**建议：丙+丁。**

## 4. 裁决点 2：enum/变体重名分叉处置

拼接单元中包间/包与主文件撞 enum 或变体名时：宿主静默覆盖（首个赢）可编译；
L2 register_enums 现状重名即 `Err` 拒绝——**行为分叉点**（D5 生成器构造性
规避了该形态）。

- **甲：L2 维持严格拒绝（建议）**——撞名程序在 L2 编译期拒并给出明确文案
  （"枚举 'X' 重复声明（跨包/主文件重名）——宿主静默取首个定义，L2 明确
  拒绝；请重命名"）；信任边界登记（R68 let 注解/R74 调用点既定严格路线
  延续——宿主"LLM 责任保证不同包不重名"的注释本身就是把撞名当错误处理的
  口径，L2 只是把它从静默变显式）。
- **乙：对齐宿主静默首个赢**——改 register_enums 为覆盖语义，弱化既有
  重复检查（该检查还服务于单文件内真重复声明的诊断），不建议。

**建议：甲。**

## 5. 裁决点 3：包名放行的传参形态

- **甲：argv 第三参逗号清单（建议）**——`self_comp.lom -- in.lom out.hex
  liba,libb`；verify 脚本从 pkg-expand 的伴随输出（或 `--list-packages`
  侧出口/固定解析）取包名传入。显式、零产物污染（不往源码里注入任何
  标记）、向后兼容（缺省=无包，单文件路径零变化——存量 hex 恒等的前提）。
- **乙：展开产物首行注入识别标记**——往编译输入里加非语言内容，污染
  诊断行号且形态怪异，不建议。
- **丙：L2 对未知模块一律静默放行 import item**——放弃 PKG005 对齐
  （typo 包名不报错，调用点才炸），回退现状，不建议。

**建议：甲。**

## 6. 技术设计（按建议档 丙+丁 / 裁决 2 甲 / 裁决 3 甲 展开）

### 6.1 宿主侧：`lom pkg-expand` 子命令（src/main.rs + cli.rs）

- 入口 `run_pkg_expand(file)`：base_dir = file 所在目录（对齐 7.8 语义）；
  无 lom.toml 时输出主文件源码原样（幂等退化为 cat——单文件项目合法）。
  有则 `resolve_dependencies` → 按宿主序（包根路径排序 + 包内文件名排序）
  收集包源码 → **剥包内 import**（逐行级：解析顶层 `from X import {...}`
  语句并剔除——复用 lexer 或行前缀匹配，实施定）→ 依序拼接（包源码
  之间与主文件之间以空行分隔）→ **stdout 输出**；包名清单输出到 stderr
  （或 `--list` 开关单独取——verify 脚本消费）。
- 失败路径：PKG001/002/003 等结构化诊断照常（复用宿主解析），rc 非零。
- Rust 测试：pkg_demo 展开（含剥 import 断言）/单文件幂等/无清单退化/
  排序确定性（同图两次输出逐字一致）。

### 6.2 L2 侧：known_pkg 放行 + 未知模块报错

- 驱动 main：argv 长度 ≥3 时解析第三参（split 逗号）进 `pkgs` 集合，
  传入 build_module → collect_sigs。
- ItImport 分派：module ∈ {string,list,map,json} 走现行逐名内建注册；
  module ∈ pkgs → **逐名校验该名是拼接 items 中的 fn/enum/变体**（查
  fns/@variant: 表——不在则"包 'X' 中无公开符号 'y'"，对齐宿主
  process_import 的 public_symbols 校验）+ as 别名注册（alias→真名映射，
  调用点按真名解析——宿主 import_aliases 语义）；**import 语句本身不产
  任何调用代码**（符号已是普通 fn）。既非内建也非 pkgs → `"未知模块
  'X'（非内建模块且不在包清单——检查 import 拼写或通过第三参声明包名）"`
  编译错误（堵静默落空）。
- 别名调用：comp_call 查 fns 前先查 alias 映射（真名签名校验——R74 口径）。
- **fn 重名**：维持现状（后写覆盖+各占槽位）——与宿主行为一致（主文件赢），
  hex 尺寸差不做字节对齐（本就不做字节级一致）。

### 6.3 校验总表（编译期 subset_err/明确错误拒绝）

| # | 形态 | 文案要点 | 宿主参照 |
|---|---|---|---|
| 1 | import 未知模块（非内建非包清单） | "未知模块 'X'" | 宿主 PKG005/wasm_codegen L554 对齐（**堵缺口**） |
| 2 | 包 import 的符号不在包 items | "包 'X' 中无公开符号 'y'" | 宿主 process_import public_symbols 校验对齐 |
| 3 | 跨包/主文件 enum·变体重名 | "枚举/变体 'X' 重复声明（宿主静默取首个，L2 明确拒绝）" | **裁决 2 甲信任边界** |
| 4 | 包名第三参与展开产物不一致（展开含 liba 清单漏 liba） | import 命中 #1 报未知模块——防御性兜底自然成立 | — |
| 5 | 主文件 import 的包符号与内建导入同名 | 现行"与用户函数/重复导入同名"检查（包 fn 已在 fns 表） | 宿主同名覆盖口径差异——既有信任边界维持 |

### 6.4 用例与 verify 适配

- **对拍用例（新目录形态 tools/selfcomp/pkg_cases/，预计 3-4 项目）**：
  101_pkg_single（单包：pkg_demo 同构——mathlib square/cube/factorial）；
  102_pkg_chain（三包链 C→B→A 桥接，D5 生成器形态）；
  103_pkg_alias（`pf_x as aliased_fn` 别名 + 包内 enum 与 match 消费）；

  verify_selfcomp.py 的正例循环对 pkg_cases 适配：宿主侧 `lom build <dir>/main.lom`；
  L2 侧 `lom pkg-expand` → 展开单元喂 self_comp（包名清单经 stderr/`--list`

## 7. 信任边界登记（本批新增，进 RFC 修订）

1. **enum/变体重名**（裁决 2 甲）：宿主静默首个赢，L2 明确拒绝——严格
   路线延续（宿主注释本就把撞名当归错误处理）。
2. **包展开职责分离**（裁决 1 丙+丁）：L2 编译对象是宿主包系统展开的
   编译单元（cargo/rustc 先例）；L2 不自行发现 lom.toml（冻结约束下
   无目录列举内建）——L2.4 自举闭环时同样经 pkg-expand（self_comp
   本身无包依赖，零影响）。
3. **诊断行号**：展开单元的行号是拼接产物的（宿主 build wasm 路径对包
   源码同样不保证逐文件行号）——非新增分叉。
4. **fn 重名 hex 尺寸差**：L2 各占槽位 vs 宿主槽位复用——行为一致，
   不做字节对齐（既有口径）。
