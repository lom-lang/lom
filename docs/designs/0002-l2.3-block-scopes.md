# L2.3 块作用域与类型预扫设计（R79/R82）

- **状态**：R79 的编译期作用域已按本设计实现；R82 的类型预扫仍待第二批整改
- **语义参照**：宿主 WASM 的 `compile_block_stmt` / `compile_block_value` 在每个块入口建立词法作用域，在出口撤销该块的 `let` 绑定；`for` 的迭代变量只在循环体内可见。
- **L2 约束**：`Map` 是引用语义；`let child = env` 不会产生隔离。`locals` 与 `localvt` 仍需在同一函数内共享，以保证 WASM local 编号唯一。

## 绑定边界

每个控制流子块在入口调用 `copy_bindings(env)`，然后把拷贝交给语句与尾表达式编译。`if` 的各分支、`while` 的循环体、`for` 的循环体以及值位 `if` 的各分支都各得一份。`for` 在自己的拷贝里先登记迭代变量，再编译循环体。顶层函数块从独立空环境开始；`match` 各臂已有独立拷贝。

子块内给已有变量赋值仍使用拷贝中的原 local 槽；子块内 `let` 遮蔽则分配新槽并只修改拷贝。退出子块只丢弃拷贝，不回写父环境。编译失败直接传播错误，不依赖恢复动作。

## 类型预扫边界

R82 的 `blk_val_ty` 需要同一套临时绑定规则：先复制入块环境，依语句顺序综合 `StLet` 的值类型与闭包签名，并登记临时绑定，再综合尾表达式。嵌套值位 `if` 各分支再各自复制当前临时环境。`match` Form B 的块类型综合复用这条规则。预扫不分配真实 local，也不修改编译期父环境；真实发射仍由块编译路径完成。

## 验收边界

- 正例：未执行分支遮蔽不改变外层值；同名局部在兄弟分支和循环体外仍读原绑定；对子块内已有绑定赋值仍写原槽；Form B 臂内嵌套控制流遵守相同规则。
- 负例：只在 `if`、`while`、`for` 子块或兄弟分支声明的名字，在块外或兄弟分支必须报未定义且不产 hex。
- R82 正例：值位 `if`、嵌套值位 `if`、Form B 臂尾的 `let x; x` 能综合并执行；其 `let` 不得流向其他分支或外层。
