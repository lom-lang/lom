## 1. 供料结论（浓缩）

1. **三通道**：`lex error`（**已坏**——`lex()` 构造点只填 `{msg,ln,cl}` 三字段，report_errors L12480 读 `e.code` 崩 `RUNTIME000 记录没有字段 'code'`；`classify_lex_msg`（L1215）定义零调用；161 负例零 lex 用例——**新发现存量 bug，随批处置见裁决点 2**）；`parse error`（正常：码+位置+文案）；`codegen error`（263 处 subset_err + 40 处裸 Err 全走此道，无码无位置——本批主对象）。
2. **行号分档**：AST 仅 4 节点带位置（ExIdent/StAssign/StHole/ExMatch 结束行）且消费点多 `_` 丢弃；语句级/调用级（callee 锚，~118 处主要簇）可低成本锚定；表达式级需 AST 加 span（违反 L718"span 不建模"既定设计、波及面最大）；纯类型工具簇（~40 处）需深链传参。**本批不做行号**——输出层无 AST 可锚，全量/主要簇传参属中批工作量，首批先做码结构化（fix 引擎吃 L2 诊断的第一层：码分派不需要位置）。
3. **145 断言兼容性**：verify_selfcomp 负例锁文案为纯 substring——**前缀/后缀附加式天然兼容**，中插式破断言。
4. **quine 连锁**：bootstrap 对尺寸只打印不断言（断言双侧一致）；连锁 = doc_audit J quine 组 6 处手工同步（非门禁硬拦，纪律性）。六模式零影响（全对拍 self_interp）。
5. **隐性连锁**：eval 127-129 三题 prompt 逐字嵌 L2 原文——改格式后与新编译器 stdout 失配（生成纪律"verbatim 采集"面），处置见裁决点 3。
6. **L1 先例**：self_interp Part E 码沿用宿主同名 + em_add 结构 + 稀疏锚点取位；lex/parse 侧 classify 关键字匹配对齐宿主 diagnostics.rs——**输出层关键字→码映射有双先例**（宿主 classify_runtime_error + L1 classify_lex_msg）。

## 2. 设计（三个子面）

### A. 码体系与输出格式（codegen error 通道结构化）

- **码族（L2 专属前缀，7 族 + 兜底）**：`L2T`（类型不符/不相容/注解）、`L2C`（调用校验：实参/arity/内建调用）、`L2U`（未定义变量/未知函数/作用域）、`L2S`（子集外形态：暂不支持/该表达式形态/子集外）、`L2V`（值参与运算：算术/比较/拼接/一元）、`L2P`（程序结构：缺 main/重名/命名约束）、`L2E`（内部错误/防御哨兵——非用户错误，独立族便于过滤）；兜底 `L2G`（未归类）。序号三位（L2T001…），映射表内一码一关键字族（同族细分共用码，首版不追求一拒绝一码）。
- **实现（输出层映射，零调用点改动）**：self_comp 新增 `classify_l2(msg) -> String`（Lom 函数，关键字匹配表 ~40 条，双先例形态）+ main 的 codegen error 打印处改为 `println("codegen error: [" + code + "] " + msg)`，`COMPILE-ERROR` 行不变。**文案主体（含 "L2.2 子集不支持:" 前缀）原样保留** → 145 锁文案天然兼容（前缀附加式）。
- **映射表质量门**：新负例断言升级——verify_selfcomp 的 EXPECTED_NEGATIVE_MESSAGES 补"码+文案"双锁（抽样 ≥30 枚升级为 `[L2xxx]` + 文案双 substring，其余维持单锁——全量 145 枚升级由实施按时间盒实裁定，如实记录升级数）；新增"全负例码非空且非 L2G 兜底比例"抽验（兜底率预期 <10%，实测为准）。
- 不动：subset_err 263 处调用点、裸 Err 40 处、`COMPILE-ERROR` 行、hex 产物（正常路径零改动→**存量正例 196+8 的 hex 构造性恒等、quine 双侧一致保持**——self_comp 源码变化使 quine 字节数变，J 锚 6 处同步新值）。

### B. lex error 通道修复（裁决点 2 甲则随批）

- 四个构造点（L385/398/453/622）补 `code` 字段（值经 `classify_lex_msg` 接线——死代码激活，对齐 L1）；report_errors 不动（读 e.code 即正常）。
- 负例锁定：新增 1-2 个 lex 错误负例（`neg_l2_lex_*`，锁 `lex error ln:cl [` 格式 + 码）进 verify_selfcomp（161→162/163）。
