# L2.3 Map 批设计方案

- **文档**：docs/designs/0006-l2.3-maps.md
- **性质**：动工前置设计（HANDOFF 约定：涉值表示扩展的批次先出设计方案再动工——闭包 0001 / String 0004 / List 0005 先例）
- **基线**：`5b86eed` / v1.2.12（2026-09-26）；self_comp.lom 7813 行；verify_selfcomp 181/181 = 79 对拍 + 102 负例
- **状态**：**设计产出（动工前置，待用户裁决）**
- **上游**：RFC-0004 修订 6/8/9/12/14/16/17（a 控制流 / b 闭包 / c1 枚举 match / c2 泛型 / String 批 / List 批 / 十五审整改）；List 批交付的 ls{T}、HOF 特化去重、cons 槽按 vt 存取是本批复用件；**Map 是 json 批的前置**（json object → Map，RFC-0004 L2.3 既定顺序 Map→json→包→return）

---

## 1. 背景与范围

L2.3 已交付 a/b/c1/c2/String/List/十五审整改七批。剩余 Map/json/包/return 四批中 **Map 批**下一个：
Map 值流过 L2 编译器（8 个 map 内建、`Map<String, T>` 类型流、map_get → Option 与
c2 的无缝对接、map_keys/values → List 与 List 批的衔接），并为 json 批铺平
（json object 解析结果是 Map）。

**本批目标**（对拍口径不变：双产物行为级一致——宿主 `lom build --target wasm`
vs L2 产物，stdout + rc 逐字；不做字节级一致）：

1. Map 值通道：`map_empty/set/get/has/remove/keys/values/size` 全部 8 内建；
   Map 在 let/参数/返回/赋值/if/match Binder/闭包捕获/泛型载荷
   （`Map<String, T>` 注解、`en:Box{mp{i64}}`、`Result<Int, Map<String, Int>>`）
   的类型流；
2. map_get 返回 `en:Option{V}` 经现有 match 模式消费（c2 零新增）；
3. map_keys/values 的键排序确定性（字节序，与宿主 Rust str Ord 同语义）；
4. **引用语义对拍**：宿主 WASM 的 Map 就地改（let 别名共享）——L2 裸指针
   天然同构，需用例锁定（与 List 不可变语义的关键区别）。

**明确不在本批**：`println(Map)` 与拼接提升的 Map 侧显示（宿主打 `{k: v}`——
与 println(List)/println(闭包)/println(Enum) 同边界，留容器显示批统一裁决）；
Map 大小比较与跨类型比较；json/包/return；Map 下标表达式（宿主无此语法，
Map 值只能经内建产生——非缺口）。

## 2. 现状与宿主参照系（读码结论，行号 @ 5b86eed，供料已逐处实证）

### 2.1 L2 现状（self_comp.lom 7813 行）

前端已就绪：`TyGeneric("Map", [T])` 类型形态（与宿主一致）、`ExCall` 内建调用
形态。self_comp 自身大量使用 map 内建（L2:32 导入 7 个，无 map_values——运行在
宿主解释器载体上，与"编译侧支持被编译程序用 Map"是两回事，本批不动其写法）。
编译侧拒绝点（供料实证）：

| 位置 | 现状 |
|---|---|
| `ty_vt_with_params`（L2:2629-2643 TyGeneric 分支） | 仅 `name == "List"` 走 `ls{T}`；`Map` 落泛型枚举查表 → **"未知泛型枚举类型 'Map'"**（签名层即拒） |
| `Ty` 兜底（L2:2672-2673） | "该参数/返回类型（String/List/Map/记录/元组留后续批次）" |
| import 注册（collect_sigs L2:7506-7549） | 只有 `module == "string"`（L2:7510）/ `"list"`（L2:7526）分支——**`from map import` 被静默忽略**，导入名不注册 |
| `comp_call`（L2:4071；idx==-2 分派 L2:4099-4107） | map 名不在 fns → "调用未知函数 'map_get'"（误导性文案——首个要堵的点） |
| `comp_println`（L2:4297-4331） | 仅 i64/f64/st/i32 四分支；文案 L2:4323 只列 List/枚举，需扩 Map |
| 预扫 `scan_ex` 白名单（L2:6154-6157） | `map_empty` 不在 alloc 类白名单；`need_heap` 兜底（L2:4493-4498）会抓漏但报"内部错误" |
| `vt_merge/vt_compatible`（L2:2477/2509） | 只认 `?`/`ls{}`/`en:` 合流——`mp{}` 需新增 |

### 2.2 宿主参照系（src/wasm_codegen.rs=WC / interpreter.rs=IN / typechecker/builtins.rs=TC）

- **值表示**：`TAG_MAP=10`（WC:140）。Map 对象 `[buckets: i32][cap: i32][size: i32]`
  （头 12B），桶 `[state: i32][key_off: i32][val: i64]` 步长 16——state 0 空/1 用/
  2 墓宝；bump arena 零初始化故空桶免费（WC:138-139）。**键恒 String**（TC 8 内建
  第 2 参全为 `Type::String`）；桶存 i32 `key_off`，比较时按 `[len][bytes]` 布局
  逐字节——与 L2 st 布局逐字节一致（L2:4505 注释）。
- **helper 家族**（WC:4249-4967）：RT_MAP_NEW（头 12B + 256B 桶区，cap=16）；
  RT_MAP_PROBE（FNV-1a `h=2166136261, (h^b)*16777619` i32 回绕 → `h & (cap-1)`
  线性探测；state 0 返回负值编码插入槽、state 2 记 first_free 继续、state 1 逐键
  比较命中返回桶下标）；RT_MAP_SET（覆盖/插入 + `size*2 > cap` 触发翻倍 rehash，
  仅搬 state==1 桶）；RT_MAP_GET（**命中构造 Some 对象 `[idx=2][n=1][v]` 16B、
  未命中 None `[idx=3][n=0]` 8B**——与 L2 变体表 Some=2/None=3 逐值对齐）；
  RT_MAP_HAS；RT_MAP_REMOVE（墓碑 + size--，**返回 Unit**）；RT_MAP_KEYS
  （key_off 收集 + 插入排序 RT_STR_CMP 字节序 + 尾起 cons 正序）；
  RT_MAP_VALUES（复用 keys 序逐键 probe 取 val + 反转）。
- **调用点**（WC:2373-2410）：map_empty/set/get/has/remove/keys/values 走 helper
  call；**map_size 内联**（load size@8）。参数 tag 校验 `eval_args_tagged`
  （第 1 参 TAG_MAP、第 2 参 TAG_STR，不符运行时 trap——编译期不拒）。
- **typechecker**（TC:303-396）：`map_any = Generic("Map", [_Any])` **单参数**；
  map_empty→`Map<_Any>`、map_set→Unit、map_get→`Option<_Any>`、map_has→Bool、
  **map_remove→Bool**、map_keys/values→`List<_Any>`、map_size→Int——值类型
  全部 deferred（`_Any`）。
- **interpreter**（IN）：`Rc<RefCell<HashMap>>` **引用语义**（map_set 就地改、
  let 别名共享，IN:48-51）；map_get 构造 Some/None 裸枚举（IN:1844-1859）；
  **map_remove 返回 Bool**（IN:1882-1884）；map_keys/values 键排序（Rust str
  Ord，IN:1897-1930）。
- **宿主双后端分叉（本设计实证，规划者亲手复现）**：`println(map_remove(m,"a"))`
  树遍历解释器打 `true/false`，宿主 WASM 打 `()/()`——**宿主内部三分裂**
  （IN/TC=Bool vs WC=Unit）在双后端可见。这是宿主既有事实（非本批引入），
  裁决点 2 处理，另实证 map_get 双后端一致打 `Some(1)`。

### 2.3 关键差异：宿主 tagged vs L2 untagged 对 Map 的影响

与 List 批（designs/0005 §2.3）同型，多一层**值多态**：

1. **桶 val 槽宽**：宿主桶 val 恒 8B tagged（probe/hash/排序/rehash 搬运全与值
   类型无关，8B 盲拷）。L2 untagged 下槽物理恒 8B、**访问按值 vt 选宽度**
   （f64 → f64.load/store 直写、i32 → extend/wrap、其余 i64 直存）——与 cons 槽
   （L2:5236-5257）/闭包 env 槽（0001 裁决 D）完全同型。probe/rehash 搬运仍 8B
   盲拷，值 vt 只影响 set 写入 / get·values 读出的装载发射与 helper 特化键。
2. **helper 特化**：probe/new/has/remove/keys 与值 vt 无关（单型）；set/get/values
   按 V 特化（`"mp_set|" + V` 键，ls HOF 特化先例 L2:5484-5490）；map_eq 若做
   同族（B2 档）。
3. **键通道**：st 布局与宿主逐字节一致，FNV-1a/逐键比较/排序**直接平移**
   （helper 体是发射的 WASM 指令，i32 乘法回绕语义同宿主，无 Lom 层溢出问题）。
4. **引用语义天然对齐**：L2 Map 值 = 裸指针，let/传参拷指针、map_set 就地改
   ——与宿主 WASM（tagged 指针共享）和解释器（Rc 共享）同语义，零特殊处理。

## 3. 值表示（既定路线延伸，不设裁决点）

沿 0001 裁决 A甲 untagged 路线自然延伸（List 批 ls{T} 同族）：

- **vt 编码**：新增 `mp{V}`——**单参数**（与宿主 typechecker `Generic("Map",[_Any])`
  一致；键恒 String 不进 vt）。示例：`mp{i64}`、`mp{f64}`、`mp{st}`、`mp{ls{i64}}`
  （嵌套 List 值）、`mp{mp{i64}}`（嵌套 Map 值）、`en:Box{mp{st}}`、
  `en:Result{i64;mp{st}}`（泛型载荷）、闭包签名 `mp{i64}->i64`（sig 串按逗号/@
  分隔——`mp{...}` 不含这两个字符，c2 花括号深度拆分规则天然覆盖）。
- **`mp{?}` 万能型**：`map_empty()` 无上下文返回 `mp{?}`——由 `map_set(m, k, v)`
  结构补全为 `mp{v_vt}`、由 `let m: Map<String, Int> = map_empty()` 注解补全
  （ls{?} 的 c2 `?` 机制复用，绑定层细化进 `scan_block_lets` 同步）；裸 `mp{?}`
  进入需值宽度的位置（get/values/binder 模式/eq）明确拒绝。
- **WASM 值 = i64 裸指针**：Map 头对象地址（≥8）。与 Int 的区分纯编译期 vt。
- **对象/桶布局照宿主平移**：头 `[buckets][cap][size]` 12B、桶 16B 步长
  `[state:i32][key_off:i32][val:8B]`。
- `vt_hex("mp{...}") = "7e"`（i64 载体，L2:2689 同族）。
- **heap_on 预扫扩**：`map_empty` 进 scan_ex 的 alloc 类白名单（L2:6154 先例）；
  Map vt 注解/`mp` vt 闭包捕获同入 needs_heap 保守口径。

## 4. 裁决点 1：批次范围档位

- **B1 值通道 + 8 内建全量（基线，必含）**：`mp{V}` 类型流（ty_vt/infer/comp/
  预扫/let 注解一致性/赋值/if/match Binder/闭包 sig 与捕获/泛型载荷解禁）；
  8 内建（empty/set/get/has/remove/keys/values/size——size 内联对齐宿主，其余
  helper；**values 复用 keys 序 + probe，成本增量小，随 B1 交付**）；`mp{?}`
  补全；map_get → `en:Option{V}` 对接 c2 match；引用语义对拍用例；rehash
  （>16 键）与墓碑复用对拍；多字节 UTF-8 键对拍。
- **B2 Map 结构相等（建议纳入）**：`==`/`!=` 对 `mp{V}` 走特化递归 eq（size 等 +
  逐键 probe 对方 + 值按 V 递归：i64/i32/f64/st 走既有 opcode/helper、嵌套
  ls/mp 递归特化；en/cl 值元素明确拒——负例锁）。机制与 List 批 B3（rt_ls_eq
  特化族）同根，List 已趟平，增量小。宿主蓝本 RT_MAP_EQ（WC:4886-4967）。
- **降档序**：若工期压力，B2 可剥离为紧随小批（B1 独立可交付）。

**建议：B1+B2 同批。**

## 5. 裁决点 2：map_remove 返回值对齐（宿主双后端分叉处置）

宿主三分裂（实证）：树遍历解释器与 typechecker 返回 **Bool**（IN:1882/TC:359），
宿主 WASM 返回 **Unit**（WC:4627）；同一程序 `println(map_remove(m,"a"))`
双后端分叉（`true/false` vs `()/()`）。L2 的对拍基准是宿主 WASM。

- **甲：本批不动宿主，L2 对齐宿主 WASM（Unit）——建议**。对拍口径零障碍
  （`let _ = map_remove(...)` / 直接语句调用形态双侧一致）；宿主双后端分叉
  登记为**宿主既有差异挂账**（是否修宿主 WASM 侧对齐 Bool 由用户另裁——修则
  三处一致，属宿主行为改动需独立小批与全量回归）；L2 的 map_remove 签名
  ret=void，`let b = map_remove(...)` 在 L2 编译期拒（void 值绑定既有检查），
  宿主解释器该写法合法——**信任边界登记**（用例避开）。
- **乙：顺手修宿主 WASM 对齐 Bool（L2 跟 Bool）**。宿主 src 改动（RT_MAP_REMOVE
  返回值构造 + WC:118 注释），三处归一；代价：本批从"L2 零宿主改动"变"宿主
  行为改动包"，eval 双后端 121/121 与全部 golden 需确认无 map_remove 返回值
  消费（规划者已 grep：eval 参考解与示例均以语句形式调用，无消费——但全量
  回归仍须实证零影响）。
- **丙：L2 对齐解释器（Bool）**——与对拍基准分叉，对拍用例无法消费返回值，
  自缚手脚。不建议。

**建议：甲。**

## 6. 裁决点 3：编译期严格性包

宿主是"运行时 tag trap + typechecker deferred"（map_set 传非 Map 在
`eval_args_tagged` trap；`mp{i64}` 混入 Float 值在宿主不可能——tagged 自描述）。
L2 vt 精确跟踪下编译期全在手：

- **甲：编译期严格拒绝（建议）**——① 第 1 参非 `mp{...}` 拒（"期望 Map 得
  vt"）；② 键非 String 拒；③ `mp{X}` 与值 vt 不相容的 set/赋值/let 注解拒；
  ④ 裸 `mp{?}` 进 get/values/binder 拒。R68（let 注解）/R74（调用点）/List 批
  裁决 2 甲既定路线延续。
- **乙：对齐宿主运行时**——放弃编译期校验产 trap 的 wasm。违背既定信任边界
  路线，不建议。

**建议：甲。**

## 7. 技术设计（按建议档 B1+B2、裁决 2 甲、裁决 3 甲展开）

### 7.1 模块布局与 helper 家族

无新 section（data/code/global/memory/table 按既有条件发射）。helper 全走
extra 区机制（`cgh "hidx:<name>"` 去重 + `"|"` 特化键）：

| helper | 签名（WASM） | 蓝本 | 备注 |
|---|---|---|---|
| mp_new | () -> i64 | build_map_new WC:4249 | alloc 头 12B + 桶区 256B（cap=16） |
| mp_probe | (i64 m, i64 k) -> i32 | build_map_probe WC:4290 | FNV-1a 内联（WC:4269）+ 线性探测 + 墓碑 first_free + 负值编码插入槽 |
| mp_set\<V\> | (i64 m, i64 k, v:V) -> () | build_map_set WC:4386 | 覆盖/插入；val 写入按 V（f64 直写/i32 extend/其余 i64）；rehash 翻倍仅搬 state==1 |
| mp_get\<V\> | (i64 m, i64 k) -> i64 | build_map_get WC:4546 | Some `[2][1][v]` / None `[3][0]` 对象构造（与 L2 变体表 idx 一致）；载荷写入按 V |
| mp_has | (i64 m, i64 k) -> i32 | build_map_has WC:4584 | probe ≥ 0 |
| mp_remove | (i64 m, i64 k) -> () | build_map_remove WC:4592 | 墓碑 + size--；**返回 void（裁决 2 甲）** |
| mp_keys | (i64 m) -> i64 | build_map_keys WC:4630 | 收集 + 插入排序（st_cmp 复用）+ 尾起 cons 正序 |
| mp_values\<V\> | (i64 m) -> i64 | build_map_values WC:4775 | 复用 mp_keys 序逐键 probe；val 读出按 V；cons 后反转 |
| mp_eq\<V\>（B2） | (i64 a, i64 b) -> i32 | build_map_eq WC:4886 | size 等 + 逐键 probe + 值按 V 递归（标量/st/嵌套 ls/mp；en/cl 拒） |

调用点：`map_size` 内联（`load size@8`）；`map_empty` 若值 vt 已知可直接
`call mp_new`；其余 eval 参数 + call。**参数求值序与宿主一致**（先参数后分派）。

### 7.2 类型流与编译路径

- `ty_vt_with_params`：`TyGeneric("Map", [T])` → 参数数校验 1 → `"mp{" + 内层 + "}"`；
  其余泛型维持现拒。
- import 注册：collect_sigs 加 `module == "map"` 分支 + `mp_builtin_entry`
  （8 内建的 helper 名/arity/prms/ret；先例 li_builtin_entry L2:6986）——
  **同时堵"静默忽略"缺口**（导入名不在表 → "未知内建 '<module>.<name>'"，
  修正误导性"调用未知函数"文案）。
- `comp_call` idx==-2 分派扩 `starts_with("map_")` → comp_map_builtin。
- **元素 vt 推导**（builtin_rv）：`map_empty()` → `mp{?}`；`map_set(m,k,v)` →
  void（m 为 `mp{?}` 时绑定层细化为 `mp{v_vt}`——ls{?} 先例进 scan_block_lets）；
  `map_get(m,k)` → `en:Option{V}`（V = m 的内层；`mp{?}` 裸读拒）；
  `map_has` → i32；`map_remove` → void；`map_keys` → `ls{st}`；
  `map_values(m)` → `ls{V}`；`map_size` → i64。
- `vt_merge/vt_compatible` 扩 `mp{` 前缀（花括号深度拆分函数复用）。
- **match**：map_get 结果的 `Some(v)/None` 模式走 c2 现有 PatVariant（零新增）；
  `mp{V}` 值本身的 Binder 绑定 → vt 进环境（c1 臂绑定机制）；裸 `mp{?}` binder 拒。
- **闭包/泛型载荷**：`mp{...}` 流经 sig 串、捕获槽（8B i64 直存）、c2 实例
  `en:Box{mp{i64}}` 载荷——编码无冲突，自动获得。
- **for 迭代**：维持三向（Int/String/List）——`mp` 拒（"for 迭代仅支持
  Int/String/List"既有文案天然覆盖）。

## 9. 信任边界登记（本批新增，进 RFC 修订）

1. **编译期严格包（裁决 3 甲）**：校验 #1-#4——宿主运行期 trap 或 deferred
   放行，L2 编译期拒（R68/R74/List 批甲既定路线延续）。
2. **map_remove 返回 Unit（裁决 2 甲）**：L2 对齐宿主 WASM；宿主**解释器/TC
   返回 Bool 的双后端分叉是宿主既有事实**（本设计实证 `true/false` vs `()/()`），
   登记挂账待用户另裁是否修宿主；`let b = map_remove(..)` 在 L2 拒（宿主解释
   器合法）——用例避开。
3. **println(Map) 与拼接提升 Map 侧**（校验 #6/#7）：宿主合法（`{k: v}`）；
   L2 拒——println(List)/println(闭包)/println(Enum) 同型，留容器显示批统一裁决。
4. **map_keys/values 键排序**：字节序 Rust str Ord——与宿主同语义平移，非差异。
5. **mp_eq 值边界**（B2）：en/cl 值拒——List B3 同族先例。
6. **map_get 的 Option 显示**：宿主双后端一致打 `Some(1)`（枚举 display）；L2
   println(枚举) 既拒（c1 先例）——用例以 match 消费，非新增差异。
