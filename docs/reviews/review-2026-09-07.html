3.1 W 工作包：三处 wasm 修复的逻辑推演（git show eb0ce7e）

① emit_variant_test idx 读 tag 守卫（src/wasm_codegen.rs:957 起）：旧实现把 tag==6 与 i32.load(s>>4) 两个操作数先后压栈再 AND——WASM 栈机急切求值，load 无条件执行，非枚举 scrutinee（大 Int）的 >>4 是野地址即 OOB。新实现 tag==6 → if (result i32) { load idx } else { -1 } 后与 vidx 比较——tag 不符给 -1（变体索引为小非负整数，-1 不可能命中），语义等价且无盲读。推演成立。

② Pattern::Variant 载荷提取推迟（同文件 :931 起）：旧实现把 i64.load(s>>4 + 8+8k) 与臂测试平铺 AND，0 参枚举（仅 8 字节头对象）贴线性内存末尾时 +8 载荷读越界——这正是 8.4 挂账的 tok_disc 野值真相。新实现：emit_variant_test 结果留栈作条件，if (result i32) 内做载荷提取 + 子模式 AND 链（first 标志保证首项不加 AND），else 给 0；sub.is_empty()（无参 Binder 臂）时不生成 if、仅留 variant_test 结果。推演成立；配套 e2e 测试 e2e_binder_arm_vs_nullary_scrutinee 锁定 0 参 scrutinee 落臂语义（实测输出 0/7）。

③ Stmt::For 三个分派 if 补 Label::If（同文件 :1110/:1142/:1176）：for 体编译在 Int/Str/List 三个分派 if 之内，br $ret 的深度按 label 栈计算——分派 if 未入栈则 for 体内 return/? 的 br 深度少算 2-3 层、提前返回被静默吞掉（v0.12.0/7.6 起潜伏）。修复为三个分派 if 各 push、end 后各 pop，压弹严格对称（else 分支共享所属 if 的 label，无需额外压）。推演成立；配套 e2e_return_inside_for（期望 2/7）与 e2e_try_inside_for（期望 err: boom）实测通过。
