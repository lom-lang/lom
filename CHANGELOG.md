## v1.14.0 (2026-10-21)

> **Previous repository milestone: v1.14.0 (2026-10-21; agent execution trace per [designs/0026](docs/designs/0026-agent-execution-trace.md), user-adjudicated with all four decision points resolved as recommended; versioned minor per the decision table's user-visible-new-capability row; pure CLI flag family + interpreter instrumentation — zero language-surface change; repository tag at `b07c6d1`, CI run `39646107026` seven jobs green — first run green; not externally published)** — the run mode gains **`--trace`**: a call-level JSONL event stream (`lom-trace/v1`) for agents. Each user-function/closure entry emits a `call` event (name, `ln:cl` site, frame `depth`, arguments) and each exit a `return` or `call-error` event — the latter carrying the verbatim `[RUNTIMExxx]` code, so a failed run now shows *which call layer, with what arguments*, not just the final error. The flag family: `--trace` (default off; the off state costs exactly two `Option` checks per user call), `--trace-out <file>` (default sink stderr, stdout stays the program's product; the file sink is NDJSON append-write), `--trace-max-events <n>` (default 10000, `0` = unlimited, cap-hit streams end with `truncated:true`), `--trace-builtins` (default off — builtin calls enter the trace only on demand). Value serialization is `to_display` semantics plus trace-only truncation (120 chars / nesting depth 3, overflow becomes shape annotations like `[List len=20000 …]`); the `to_display` core is untouched and `println` output is byte-identical. Applicability boundary: the interpreter run mode only — AOT `lom build` artifacts never pass through the interpreter and produce no trace. Baseline unchanged by construction: quine **272925** byte-identical, verify_selfcomp 368/368, Rust **581→593** (+12 trace unit tests; 40 integration unchanged), eval 129/129 both backends; trace-off A/B bench (call_density n=10^6 / lookup n=800) zero regression.
